# RegimeDip v1e — BTC race bot

A long-only CBBTC bot for the 24-hour BTC race: it buys full-size into
60-bar pullbacks (dip) and deep 720-bar washouts (rebound), each with a
hard stop and a 2:1 take or a trailing exit, at most 4 trades per window.
